## 경로 실험실

17 × 11 격자에서 방문자가 벽, 출발점(S), 도착점(G)을 바꾸고 BFS로 최단 경로를 찾습니다. 상하좌우 이동 비용은 모두 1이며 대각선 이동은 허용하지 않습니다. 애니메이션, 일시정지, 한 단계 실행, FIFO 큐 표시, 이동 횟수, 경로가 없는 경우의 안내를 제공합니다. 모바일과 키보드를 지원합니다.

### UI에서 알고리즘까지

- `index.html`의 `#run`(탐색 시작)과 `#step`(한 단계) 버튼
- `app.js`의 클릭 핸들러 → `prepare()` → `breadthFirstSearch()`
- `bfs.js`에서 배열과 head 인덱스로 FIFO 큐 구현, 방문 여부와 거리 저장, parent 배열로 경로 복원
- `app.js`의 `advance()`가 실제 탐색 기록을 지도와 큐에 표시

BFS의 시간 복잡도는 O(V + E), 공간 복잡도는 O(V)입니다. 큐 전체를 단계마다 복제하지 않고 head/tail 인덱스를 저장합니다. 화면 갱신과 애니메이션 비용은 별도입니다.

## 확인 방법

1. 사이트의 **경로 실험실**에서 **탐색 시작**을 누릅니다. 초록색 최단 경로와 이동 횟수를 확인합니다.
2. **벽 모두 지우기** 후 기본 출발·도착점으로 실행하면 최단 이동 횟수는 **12**입니다.
3. **벽 편집**으로 지도를 변경하거나 **출발점 / 도착점**을 선택해 새 위치를 클릭합니다. **한 단계**로 큐가 먼저 들어온 칸부터 처리되는지 확인합니다.
4. 출발점의 상하좌우를 벽으로 막으면 도착할 수 없다는 안내가 나옵니다.
5. 지도에 Tab으로 진입하고 방향키로 칸을 이동한 뒤 Enter/Space로 편집할 수 있습니다.
